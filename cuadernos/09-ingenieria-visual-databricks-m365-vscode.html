Diagnóstico Técnico: Desacoplamiento de Datos y el Patrón «Crítico Estético» en 2 Pasos

Pedirle a un modelo de lenguaje un diseño «premium, moderno y con animaciones avanzadas» produce por regresión estadística plantillas tipo Bootstrap de 2020: sombras difusas exageradas (shadow-xl), fondos grises planos (#f3f4f6), colores primarios saturados y transiciones bruscas (transition: all 0.3s ease). Además, cuando el agente debe calcular la lógica de datos y escribir la interfaz en un solo turno, comprime el CSS y el JavaScript para ahorrar tokens de salida.

🔑 Regla de Oro #1: Arquitectura de 3 Bloques Estrictos en el HTML

El fallo que reduce un 60% la calidad visual de los dashboards generados por IA es incrustar los datos en mitad del HTML o dentro de la configuración de las gráficas. Todo entregable HTML debe obligar al agente a dividir el archivo en tres compartimentos estancos:

  1. Bloque 1 — Motor de Estilos y Design Tokens (<style> con Micro-CSS Fallback 100% Zero-CDN): Grid Bento nativo de 12 columnas, variables CSS en :root (Dark #060913) y html.light (Executive Slate #f8fafc), tipografía numérica tabular (font-variant-numeric: tabular-nums), curvas físicas cubic-bezier(0.16, 1, 0.3, 1) y shader CSS de iluminación especular (.sp-card). PROHIBIDO depender de cdn.tailwindcss.com en producción bancaria.
  2. Bloque 2 — Payload de Datos Aislado (<script id="data-payload">): Un único objeto global inmutable (window.REPORT_DATA = {...}) con todas las métricas, vectores de 12 meses (sparklines) y enlaces Sankey precalculados en PySpark o Python.
  3. Bloque 3 — Motor Reactivo de Renderizado e Interacción (<script id="app-engine">): Funciones puras que leen window.REPORT_DATA, hidratan el DOM, conectan eventos de filtrado cruzado (Cross-Filtering) y sincronizan instancias de Apache ECharts o motores vectoriales SVG nativos.
🛡️ Aviso de Seguridad TI Corporativa: Canales Homologados para Compartir HTML

En la inmensa mayoría de entidades financieras y grandes corporaciones protegidas por Microsoft Defender for Office 365 / Exchange Online, los archivos .html adjuntos en correos que contienen código JavaScript ejecutable son puestos en cuarentena automática o bloqueados por políticas EOP (*Exchange Online Protection*).

Rutas corporativas recomendadas para compartir dashboards sin bloqueos:
  • 1. Espacio Compartido OneDrive / SharePoint Corporativo: Sube el archivo .html a una biblioteca de SharePoint de tu unidad de negocio y comparte un enlace interno de "Solo lectura para miembros de la organización" (o renómbralo a .aspx si tu tenant permite la renderización web nativa).
  • 2. Databricks Apps / Databricks Lakeview: Publica la aplicación directamente dentro de tu workspace de Databricks para que el comité acceda autenticado mediante SSO corporativo (Entra ID) sin mover archivos binarios.
  • 3. Distribución en contenedor .zip o portal documental interno: Si necesitas enviarlo por correo o Teams, comprímelo previamente en un .zip cifrado o colócalo en el repositorio de red compartido de tu departamento.

def build_safe_payload(spark_df, max_rows=500):
    """
    Control de seguridad para Databricks displayHTML() y correo corporativo.
    Evita bloqueos de memoria en el DOM garantizando payloads < 250 KB.
    """
    row_count = spark_df.count()
    if row_count > max_rows:
        print(f"⚠️ [AVISO ARQUITECTURA]: El DataFrame tiene {row_count} filas.")
        print(f"   Recortando a top {max_rows} para evitar saturar el DOM. Pre-agrega en PySpark con .groupBy().")
        spark_df = spark_df.limit(max_rows)
    
    records = [row.asDict(recursive=True) for row in spark_df.collect()]
    payload_json = json.dumps(records, default=_spark_safe_json, ensure_ascii=False)
    size_kb = len(payload_json.encode('utf-8')) / 1024
    print(f"✅ Payload generado con éxito: {len(records)} registros ({size_kb:.1f} KB)")
    return payload_json, records

        top=Side(style="thin", color="0F172A"),

    ws["B2"] = "SEGUIMIENTO EJECUTIVO DE CANALES DIGITALES Y CARTERA COMERCIAL"

    ws.row_dimensions[3].height = 18

    headers = [
        "Línea Comercial / Canal", "Sesiones Activas", "Conversión Digital",
        "Volumen Formalizado (M€)", "Variación YoY", "RORWA Neto", "Mora (NPL)"
    ]
    ws.row_dimensions[5].height = 28
    for idx, text in enumerate(headers, start=2):
        cell = ws.cell(row=5, column=idx, value=text)
        cell.font = header_font
        cell.fill = header_fill
        cell.alignment = Alignment(horizontal="left" if idx == 2 else "right", vertical="center")

    # 5. Datos y Formatos Numéricos Explícitos

        cell = ws.cell(row=tot_row, column=c_idx)

        cell.fill = total_fill
        cell.border = border_total
        if c_idx > 2:

    widths = [42, 18, 18, 24, 16, 16, 15]
    for idx, w in enumerate(widths, start=2):
        ws.column_dimensions[get_column_letter(idx)].width = w

    ws.freeze_panes = f"B{start_row}"
    wb.save(filename)

if __name__ == "__main__":

from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN
from pptx.enum.shapes import MSO_SHAPE
from pptx.chart.data import CategoryChartData
from pptx.enum.chart import XL_CHART_TYPE

def build_executive_committee_pptx(filename="Comite_Commercial_Digital_Q4.pptx"):
    prs = Presentation()
    # 1. Configurar lienzo panorámico 16:9 Widescreen (13.333 x 7.5 pulgadas)
    prs.slide_width = Inches(13.333)
    prs.slide_height = Inches(7.5)
    blank_layout = prs.slide_layouts[6]
    slide = prs.slides.add_slide(blank_layout)

    # 2. Fondo Oscuro Institucional (#070B14)
    bg = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, 0, 0, prs.slide_width, prs.slide_height)
    bg.fill.solid()
    bg.fill.fore_color.rgb = RGBColor(7, 11, 20)
    bg.line.fill.background()

    # 3. Kicker + Action Title Cuantitativo (Pirámide de Minto)

// PATRÓN DETERMINISTA DE AUTO-INSIGHTS Y RED FLAGS EN CLIENTE (SIN LLAMADAS A APIS EXTERNAS)
function generateExecutiveNarrative(slice, hurdleRorwa = 2.50, maxStage2Pct = 7.5) {
  const deltaBps = Math.round((slice.rorwa - hurdleRorwa) * 100);
  const statusIcon = deltaBps >= 0 ? '🟢 CREACIÓN DE VALOR' : '🔴 DESTRUCCIÓN DE EVA';
  const sign = deltaBps >= 0 ? '+' : '';

  const redFlags = [];
  if (slice.stage2Pct > maxStage2Pct) {
    redFlags.push(`⚠️ Vigilancia IFRS 9: Cartera en Stage 2 (${slice.stage2Pct.toFixed(1)}%) supera el umbral de tolerancia (${maxStage2Pct.toFixed(1)}%). Activar revisión preventiva de covenants.`);
  }
  if (slice.stpPct < 65) {
    redFlags.push(`⏳ Cuello de Botella Operativo: Tasa STP (${slice.stpPct}%) por debajo del objetivo (65%), penalizando el Time-to-Cash en ${slice.ttcHours}h.`);
  }
  if (deltaBps < 0) {
    redFlags.push(`📉 Déficit de Rentabilidad: RORWA (${slice.rorwa.toFixed(2)}%) está ${Math.abs(deltaBps)} bps por debajo del Hurdle Rate. Requiere repricing de +${Math.abs(deltaBps * 1.15).toFixed(0)} bps o colateral CESCE/ICO.`);
  }

  return {
    headline: `${statusIcon} — ${slice.name}: RORWA en ${slice.rorwa.toFixed(2)}% (${sign}${deltaBps} bps vs Hurdle) y EVA neto de ${slice.eva >= 0 ? '+' : ''}${slice.eva.toFixed(1)} M€`,
    summary: `Exposición activa (EAD) de ${slice.ead} M€ con densidad RWA del ${slice.rwaDensity}% y Coste de Riesgo (CoR) en ${slice.corBps} bps.`,
    flags: redFlags.length ? redFlags : ['✅ Sin alertas críticas: todos los indicadores de riesgo (Stage 2, CoR y STP) operan dentro del apetito de riesgo del comité.'],
    prescription: slice.prescription
  };
}
