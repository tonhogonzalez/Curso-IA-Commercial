00

Introducción & La Filosofía "Alive UI"

Los dashboards empresariales tradicionales sufren un mal endémico: son estáticos, desproporcionados y funcionalmente fríos. En la era de la inteligencia artificial agencial, las consolas operativas y los paneles de analítica deben sentirse reactivos, vivos y elegantes. Esta filosofía, encarnada por referentes de la industria como PaceUI, combina la solidez estructural de shadcn/ui con físicas cinemáticas y una densidad visual optimizada.

Construir estas interfaces a mano píxel a píxel resulta ineficiente. El verdadero salto de productividad se produce cuando convertimos nuestro entorno de desarrollo (Visual Studio Code) en un estudio de diseño asistido por IA, dotándolo de agentes especializados en UX/UI y skills con directivas de diseño inmutables.

Tokens de Diseño & Retículas Técnicas

El aspecto "tecnológico y limpio" de PaceUI no se basa en decoraciones recargadas, sino en la exactitud milimétrica de sus variables. A continuación tienes los tokens extraídos directamente del núcleo CSS de PaceUI:

🎨 Tokens Fundamentales: Tema Oscuro y Superficies

CSS Variables Oficiales 
/* Inyectar en :root o en la clase .dark de tu hoja de estilos */
:root {
  --font-sans: "DM Sans", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
  --font-mono: ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace;
  --radius: 0.625rem; /* 10px: curvatura precisa para tarjetas modernas */

  /* Paleta Dark Mode Primaria (PaceUI Core) */
  --background: #0a0a0a;            /* Fondo base oscuro mate profundo */
  --foreground: #fafafa;            /* Texto principal de alto contraste */
  --card: #171717;                  /* Superficie elevada (primer plano) */
  --card-foreground: #fafafa;
  --primary: #e5e5e5;               /* Elementos de acción destacados */
  --primary-foreground: #171717;    /* Texto dentro de botones primarios */
  --secondary: #262626;             /* Contenedores secundarios */
  --secondary-foreground: #fafafa;
  --muted: #262626;                 /* Fondos atenuados */
  --muted-foreground: #a1a1a1;      /* Etiquetas, subtítulos y metadatos */
  --border: #282828;                /* Borde de alta fidelidad (1px no invasivo) */
  --input: #343434;

  /* Semántica de Métricas y Estados */
  --accent-emerald: #10b981;        /* Variaciones positivas, agentes activos */
  --accent-rose: #f43f5e;           /* Errores, latencias elevadas, alertas */
  --accent-blue: #3b82f6;           /* Trazas activas, enlaces, foco */
}

La Técnica de la Cuadrícula Matemática con Máscara Radial

Uno de los sellos distintivos de PaceUI es evitar los fondos lisos y planos. Se añade una retícula geométrica sutil mediante CSS puro que se desvanece suavemente hacia los bordes: 

.pace-grid-background {
  position: fixed;
  inset: 0;
  pointer-events: none;
  z-index: 0;
  background-image: 
    linear-gradient(to right, rgba(255, 255, 255, 0.04) 1px, transparent 1px),
    linear-gradient(to bottom, rgba(255, 255, 255, 0.04) 1px, transparent 1px);
  background-size: 40px 40px;
  /* Máscara radial para atenuar los extremos */
  mask-image: radial-gradient(ellipse at center, black 25%, transparent 75%);
  -webkit-mask-image: radial-gradient(ellipse at center, black 25%, transparent 75%);
}
💡 Regla de Tipografía: `tabular-nums`

En cualquier dashboard donde los números se actualicen en tiempo real (relojes, contadores de tokens, latencias), debes aplicar obligatoriamente la regla CSS: font-variant-numeric: tabular-nums;. Esto asegura que todos los dígitos ocupen idéntico ancho horizontal, eliminando el temblor o salto visual en la pantalla durante las actualizaciones.

03

Creación de Ficheros de Agente y Skills en tu VS Code Local

Para que tu Visual Studio Code ejecute estas directivas de diseño de forma determinista en cualquier proyecto local, organizaremos la configuración en dos capas: las Instrucciones de Agente (Globales para Copilot/Cursor) y las Skills Modulares (Especializadas y llamables).

3.1. Estructura de Directorios Recomendada en tu Proyecto Local (100% Sin MCP)

En la raíz de tu proyecto en local, crea la siguiente arquitectura de carpetas y ficheros autónomos:

mi-proyecto-dashboard/
├── .github/
│   ├── copilot-instructions.md       <-- Directivas globales inmutables para Copilot
│   └── prompts/
│       └── paceui-dashboard.prompt.md <-- Prompt File ejecutable (/paceui-dashboard)
├── design-system/
│   ├── reference-tokens.css          <-- Variables CSS y paleta oficial PaceUI
│   └── components-vault.html         <-- Bóveda local de bloques y micro-animaciones
├── skills/
│   └── paceui-styler/
│       └── SKILL.md                  <-- Definición de skill agencial para Cursor / Antigravity
└── src/
    └── dashboard.html                <-- Tu dashboard HTML objetivo

3.2. Fichero 1: `.github/copilot-instructions.md`

Este archivo instruye a GitHub Copilot Chat en VS Code para que adopte permanentemente la personalidad y los estándares de PaceUI cuando trabaje en tus archivos HTML/CSS:

📄 Contenido de `.github/copilot-instructions.md`

Copiar en tu proyecto local 
# Rol y Especialidad: Arquitecto UX/UI y Frontend de Alta Fidelidad (Estándar PaceUI)

Siempre que el usuario solicite crear, mejorar, estilizar o refactorizar un dashboard HTML:
1. **Estética Obligatoria**:
   - Usa Dark Mode por defecto: fondo `#0a0a0a`, tarjetas `#171717`, bordes sutiles `1px solid #282828`, texto `#fafafa` y muted `#a1a1a1`.
   - Incorpora la retícula técnica con máscara radial (`linear-gradient` con `mask-image`).
   - Todos los badges secundarios y tags de categoría deben tener `border: 1px dashed #3f3f46` y forma redondeada en píldora (`rounded-full`).
2. **Tipografía y Métricas**:
   - Fuente base: "DM Sans" o system fonts de alta legibilidad.
   - Aplica SIEMPRE `font-variant-numeric: tabular-nums` a los números y contadores.
3. **Micro-interacciones ("Alive UI")**:
   - Botones principales con efecto `hero-shimmer`.
   - Tarjetas destacadas con borde luminoso perimetral `border-travel`.
   - Indicadores de agentes activos con pulso verde esmeralda (`#10b981`).
   - Consolas de agente con cursor de streaming parpadeante (`caret-blink`).
4. **Composición de Componentes**:
   - Las KPI cards deben incluir: categoría en píldora dashed, cifra grande tabular, delta porcentual con badge semántico y sparkline SVG embebido al pie.
   - Tablas densas con cabeceras en mayúsculas tenues y filas con hover sutil (`rgba(255,255,255,0.02)`).

3.3. Fichero 2: `skills/paceui-styler/SKILL.md`

Para entornos como Antigravity, Claude Code o extensiones agenciales de VS Code que soportan el protocolo de Skills, crea la carpeta skills/paceui-styler/ y dentro el archivo SKILL.md:

📦 Contenido de `skills/paceui-styler/SKILL.md`

Skill Agencial Reutilizable 
---
name: paceui-styler
description: Transforma cualquier dashboard HTML rudimentario en una interfaz interactiva de alta fidelidad con el estándar PaceUI ("Alive UI"), integrando retículas matemáticas, tarjetas KPI densas, consolas de agentes en streaming y micro-animaciones CSS.
---

# Procedimiento de Ejecución de la Skill

Cuando esta skill sea invocada sobre un archivo HTML de dashboard:

## Paso 1: Inyección de Tokens y Estilos Base
Verifica si el documento tiene definidos los tokens CSS de PaceUI. Si no los tiene, inyecta en el `` las variables `:root` con la paleta de modo oscuro (`#0a0a0a`, `#171717`, `#282828`) y la fuente "DM Sans".

## Paso 2: Reestructuración de Métricas (KPI Cards)
Transforma los bloques numéricos simples en tarjetas de alta densidad con:
1. Encabezado con etiqueta en píldora con borde punteado (`dashed`).
2. Cifra principal en tamaño grande (2rem+) con `tabular-nums`.
3. Píldora de variación porcentual (verde `#10b981` para subida, rojo `#f43f5e` para bajada).
4. Micro-gráfico de tendencia Sparkline dibujado en SVG embebido sin dependencias externas.

## Paso 3: Activación del Motor Cinemático
Agrega al archivo las reglas `@keyframes hero-shimmer`, `border-travel`, `caret-blink` y `live-pulse`.

## Paso 4: Consola de Trazas del Agente
Si el dashboard interactúa con agentes o tareas en segundo plano, añade una consola monospaciada con timestamp, etiquetas coloreadas y el cursor de streaming activo.
04

Arquitectura Agencial en VS Code SIN MCP: Prompt Files y Vault Local

Si no tienes acceso a servidores MCP (Model Context Protocol), no hay ningún impedimento. La arquitectura agencial en VS Code puede funcionar de forma 100% nativa, local y offline aprovechando los Prompt Files de GitHub Copilot (.github/prompts/) y el patrón Local Component Vault (bóveda local de componentes).

💡 Las 4 Ventajas de Trabajar SIN MCP en Local
  • Zero Dependencias de Red: Sin caídas de servidores remotos, sin latencia HTTP y sin consumo de cuotas de APIs externas.
  • Velocidad Instantánea: VS Code indexa tus ficheros locales en milisegundos usando embeddings del propio editor.
  • Control Determinista del Diseño: Los snippets y animaciones de tu bóveda local no cambiarán inesperadamente por actualizaciones de un tercero.
  • Privacidad Total: El código fuente de tu dashboard nunca viaja a servicios externos de MCP.

4.1. Fichero 1: `.github/prompts/paceui-dashboard.prompt.md` (Slash Command Nativo)

En las versiones actuales de VS Code con GitHub Copilot Chat, cualquier archivo guardado en la carpeta .github/prompts/ con extensión .prompt.md se convierte automáticamente en un Slash Command ejecutable desde el chat mediante una barra diagonal (por ejemplo, /paceui-dashboard).

Crea el fichero .github/prompts/paceui-dashboard.prompt.md con el siguiente contenido:

⚡ Prompt File: `.github/prompts/paceui-dashboard.prompt.md`

Slash Command Nativo para Copilot 
---
name: paceui-dashboard
description: Transforma o genera dashboards HTML con el estandar PaceUI ("Alive UI"), integrando reticulas matematicas, tarjetas KPI densas, micro-animaciones CSS y sparklines fluidos sin librerias externas.
argument: targetFile
---

Eres un Arquitecto Frontend y Disenador UX/UI de elite especializado en el estandar de diseno de PaceUI ("Alive UI").

# Archivos de Referencia del Espacio de Trabajo
- Directivas Globales: #file:.github/copilot-instructions.md
- Boveda de Componentes: #file:design-system/components-vault.html
- Tokens de Diseno: #file:design-system/reference-tokens.css

# Objetivo de la Tarea
Revisar el archivo HTML indicado en `${input:targetFile}` (o el archivo HTML abierto en el editor) y transformarlo en una interfaz de alta fidelidad con micro-animaciones fluidas a 60 FPS.

# Reglas de Transformacion Obligatorias
1. **Tokens y Paleta Base**:
   - Aplica modo oscuro por defecto: fondo `--background: #0a0a0a`, tarjetas `--card: #171717`, bordes `--border: #282828`, texto primario `--foreground: #fafafa` y atenuado `--muted-foreground: #a1a1a1`.
   - Inyecta la fuente "DM Sans" para textos de interfaz y "JetBrains Mono" para datos tecnicos.
2. **Reticula Matematica de Fondo**:
   - Agrega `.bg-grid-pattern` con lineas de 1px cada 40px y mascara radial difuminada al centro.
3. **Tarjetas KPI ("Alive Metrics")**:
   - Sustituye cualquier tarjeta estatica por la estructura de `.kpi-card` del vault:
     * Header con etiqueta en pildora punteada (`border: 1px dashed var(--border)`).
     * Numero grande con `font-variant-numeric: tabular-nums` y recuento suave con requestAnimationFrame.
     * Badge semantico de variacion (verde `#10b981` con pulso suave).
     * Sparkline SVG autocontenido con animacion de trazado (`stroke-dasharray` y `stroke-dashoffset`).
4. **Cinematica y Micro-animaciones CSS**:
   - Botones primarios con reflejo diagonal `hero-shimmer` activo y transicion hover.
   - La tarjeta KPI principal debe tener el borde brillante perimetral `border-travel` o resplandor de acento.
   - Consola de logs de agentes con cursor parpadeante `caret-blink` y scroll automatico.
   - Barra de progreso indeterminada liquida para subprocesos.
5. **Autonomia**:
   - Todo el codigo debe ser HTML5 + CSS3 + Vanilla JS en un unico archivo sin dependencias pesadas ni frameworks de empaquetado.

4.3. Guía Paso a Paso: Cómo Invocar al Agente en VS Code SIN MCP

Con tus archivos creados en local, dispones de cuatro modalidades directas de interacción dentro de VS Code:

Método 1 Slash Command Nativo en Copilot Chat:
Abre GitHub Copilot Chat (Ctrl + Alt + I o Cmd + Option + I) y escribe simplemente:
/paceui-dashboard src/dashboard.html
VS Code leerá automáticamente el archivo .github/prompts/paceui-dashboard.prompt.md, cargará los tokens y el vault local, y generará la propuesta de refactorización visual.
Método 2 Referencia de Contexto con `#file:` en Chat General:
En cualquier panel de chat de VS Code (Copilot o Cursor), puedes anclar manualmente los archivos locales escribiendo:
"@workspace #file:components-vault.html #file:copilot-instructions.md refactoriza las tarjetas KPI de src/dashboard.html para que usen sparklines SVG animados y el botón con shimmer."
Método 3 Edición Rápida In-line (Ctrl + I / Cmd + I):
Abre tu archivo HTML en el editor de VS Code, selecciona un bloque `<div>` que contenga una métrica fea o anticuada, presiona Ctrl + I (o Cmd + I) y pide al agente in-line:
"Estiliza este bloque según #file:components-vault.html como una tarjeta KPI PaceUI con efecto hover y tabular-nums."
Método 4 Herramientas Agenciales Modulares (Antigravity / Claude Code / Cline):
Si utilizas extensiones basadas en agentes autónomos con soporte de skills, ejecuta en la terminal o en la barra de prompts:
/paceui-styler src/dashboard.html
El asistente leerá el fichero skills/paceui-styler/SKILL.md, ejecutará los 4 pasos secuenciales y actualizará tu archivo de forma transparente.

    /* ==========================================================================
       LOGICA DE MICRO-ANIMACIONES EN VANILLA JS

    // 1. Contador Ticker suave al cargar la pagina
    function animateCounters() {
      const counters = document.querySelectorAll('.counter-num');
      counters.forEach(counter => {
        const target = parseFloat(counter.getAttribute('data-target'));
        const isDecimal = target % 1 !== 0;
        const duration = 1200; // ms
        const startTime = performance.now();

        function update(currentTime) {
          const elapsed = currentTime - startTime;
          const progress = Math.min(elapsed / duration, 1);
          // Easing: cubic ease-out
          const easeOut = 1 - Math.pow(1 - progress, 3);
          const currentVal = target * easeOut;

          counter.textContent = isDecimal ? currentVal.toFixed(2) : Math.round(currentVal);

          if (progress < 1) {
            requestAnimationFrame(update);
          } else {
            counter.textContent = isDecimal ? target.toFixed(2) : target;
          }
        }
        requestAnimationFrame(update);
      });
    }

    // 2. Disparador interactivo de tareas del agente
    let taskCounter = 804;
    function triggerAgentTask() {
      const btn = document.getElementById('actionBtn');
      const btnIcon = document.getElementById('btnIcon');
      const btnText = document.getElementById('btnText');
      const consoleBox = document.getElementById('consoleLog');
      const streamAnchor = document.getElementById('streamAnchor');

      // Estado activo del boton
      btn.style.pointerEvents = 'none';
      btnIcon.textContent = '⏳';
      btnText.textContent = 'Dispatching task...';

      setTimeout(() => {
        const time = new Date().toTimeString().split(' ')[0];
        const newLog = document.createElement('div');
        newLog.innerHTML = `<span style="color: #71717a;">[${time}]</span> <span style="color: #38bdf8;">EXEC</span> Injected TSK-${taskCounter} from local vault into DOM.`;
        consoleBox.insertBefore(newLog, streamAnchor);
        consoleBox.scrollTop = consoleBox.scrollHeight;

        // Anadir fila a la tabla
        const tableBody = document.getElementById('taskTableBody');
        const newRow = document.createElement('tr');
        newRow.innerHTML = `
          <td style="font-family: var(--font-mono);">TSK-${taskCounter}</td>
          <td>Vault Refactor Agent</td>
          <td style="color: var(--muted-foreground);">Sparkline Micro-chart</td>
          <td><span style="color: #34d399; font-weight: 600;">Completed</span></td>
        `;
        tableBody.appendChild(newRow);

        // Actualizar contador
        const subagentsEl = document.getElementById('subagentsCount');
        let currentSub = parseInt(subagentsEl.textContent) || 14;
        if (currentSub < 16) {
          subagentsEl.textContent = currentSub + 1;
        }

        // Re-disparar animacion de sparklines
        document.querySelectorAll('.sparkline-path').forEach(p => {
          p.style.animation = 'none';
          p.offsetHeight; // trigger reflow
          p.style.animation = 'drawSparkline 1.4s cubic-bezier(0.16, 1, 0.3, 1) forwards';
        });

        taskCounter++;
        btn.style.pointerEvents = 'auto';
        btnIcon.textContent = '⚡';
        btnText.textContent = 'Trigger Agent Task';
      }, 700);
    }

Checklist de Validación y Rendimiento 60 FPS

Antes de dar por finalizado un dashboard generado por agentes en VS Code, pasa esta lista de verificación técnica para garantizar que el rendimiento y la accesibilidad cumplan con los estándares profesionales de PaceUI:

📋 Checklist Técnico de Calidad PaceUI
  • GPU Acceleration en Animaciones: Toda animación (shimmers, pulso, traslación de tarjetas) debe usar exclusivamente transform y opacity. Prohibido animar width, height, top o margin para evitar layout reflows costosos.
  • Contraste WCAG AAA: Verifica que los textos sobre fondo #171717 utilicen #fafafa (ratio superior a 12:1) y que los textos muted #a1a1a1 no bajen de 4.5:1.
  • Estabilidad Geométrica: Asegúrate de que los contadores numéricos y métricas activas cuenten con tabular-nums.
  • Responsive Boundaries: Ningún elemento debe desbordar horizontalmente la pantalla. Los layouts deben usar grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)) para adaptarse a dispositivos móviles.
