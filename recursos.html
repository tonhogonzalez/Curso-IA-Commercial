Playground Interactivo (Python)

Prueba conceptos de programación y algoritmos directamente en tu navegador. Pyodide se encargará de ejecutar el código Python localmente.

# Un pequeño script para probar la generación de datos
import random

def simular_atencion():
    print("Simulando Mecanismo de Atención (Transformers)...")
    tokens = ["El", "banco", "de", "pescados"]
    
    for token in tokens:
        peso = random.uniform(0.1, 0.9)
        print(f"Token: '{token}' -> Peso de atención al contexto: {peso:.2f}")
        
simular_atencion()

Herramientas y Lecturas Recomendadas

  • Hugging Face

    El repositorio principal de modelos de IA de código abierto, datasets y herramientas como la biblioteca Transformers.

  • Common Crawl

    Archivo abierto de la web que sirve como conjunto de datos principal para entrenar grandes modelos de lenguaje (LLMs).

  • Attention Is All You Need (Paper)

    El paper original de Google (2017) que introdujo la arquitectura Transformer y revolucionó la IA generativa.
