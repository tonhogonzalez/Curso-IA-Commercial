# Simulación de Softmax y Atención en Python
import math

def softmax(scores):
    exp_scores = [math.exp(s) for s in scores]
    total = sum(exp_scores)
    return [round(s / total, 3) for s in exp_scores]

tokens = ["Pep", "explica", "Transformers", "en", "Arpa"]
raw_scores = [1.2, 0.4, 3.8, 0.1, 2.1]
attention_weights = softmax(raw_scores)

for token, weight in zip(tokens, attention_weights):
    bar = "█" * int(weight * 30)
    print(f"{token:14} {weight:5.3f} | {bar}")

4. Herramientas y Lecturas Esenciales

  • Hugging Face Hub & Transformers

    Ecosistema de referencia para pesos abiertos de LLMs, cuantizaciones GGUF/AWQ y datasets de entrenamiento.

  • Attention Is All You Need (Vaswani et al., 2017)

    El paper fundacional de Google Brain que introdujo la arquitectura Transformer y el mecanismo de autoatención.

  • Decoupled Weight Decay Regularization (AdamW)

    Paper de Ilya Loshchilov y Frank Hutter que solucionó la integración de Weight Decay en Adam, estándar de facto en LLMs.
